## 1. Основные теоретические сведения

Функция задана таблицей:

| $x$ | $x_0$ | $x_1$ | $\dots$ | $x_n$ |
|-----|-------|-------|---------|-------|
| $y$ | $y_0$ | $y_1$ | $\dots$ | $y_n$ |

**Интерполяционным сплайном степени $m$** называется функция $S(x)$, удовлетворяющая следующим условиям:
1. На каждом отрезке $[x_i, x_{i+1}]$, $i = 0, 1, \dots, n-1$, совпадает с некоторым многочленом степени $m$.
2. $S(x_i) = y_i$, $i = 0, 1, \dots, n$ (условия интерполяции).
3. $S(x)$ непрерывна на $[a, b]$ со всеми своими производными до порядка $m-k$ включительно (число $k$ называется **дефектом сплайна**).

Задача заключается в построении интерполяционного сплайна. Тогда значения функции $f(x)$ приближённо вычисляются как значения $S(x)$, т.е. исходная табличная функция аппроксимируется сплайном.

Наиболее применимыми на практике являются **кубические сплайны** ($m=3$). Их построение и является темой этой лабораторной работы.

### Кубические сплайны ($m=3$, $k=1$)

Пусть $m=3$, $k=1$. Обозначим шаги таблицы:
$$h_i = x_{i+1} - x_i, \quad i = 0, 1, \dots, n-1$$

На каждом частичном отрезке $[x_i, x_{i+1}]$ сплайн $S_i(x)$ определяется **интерполяционной формулой Эрмита**:
$$S_i(x) = y_i \varphi_1\left(\frac{x-x_i}{h_i}\right) + y_{i+1} \varphi_2\left(\frac{x-x_i}{h_i}\right) + h_i \left[ m_i \psi_1\left(\frac{x-x_i}{h_i}\right) + m_{i+1} \psi_2\left(\frac{x-x_i}{h_i}\right) \right] \quad (1)$$
где $m_i = S'(x_i)$ — подлежащие нахождению параметры (наклоны). Формула Эрмита обеспечивает непрерывность сплайна и его первой производной. Непрерывность $S''(x)$ достигается подбором наклонов $m_i$.

Величины $m_0, m_1, \dots, m_n$ находятся как решение системы линейных уравнений:
$$\mu_i m_{i-1} + 2m_i + \lambda_i m_{i+1} = d_i, \quad i = 1, 2, \dots, n-1 \quad (2)$$
где:
$$\mu_i = \frac{h_{i-1}}{h_{i-1} + h_i}, \quad \lambda_i = \frac{h_i}{h_{i-1} + h_i}, \quad d_i = 3\left(\mu_i \frac{y_i - y_{i-1}}{h_{i-1}} + \lambda_i \frac{y_{i+1} - y_i}{h_i}\right)$$

Система недоопределённая: не хватает двух уравнений для её замыкания. Для этого используются **граничные условия**.

#### Виды граничных условий
1. **Условия на производные в граничных узлах:** Если известны $f'(x_0)$ и $f'(x_n)$, то:
   $$m_0 = f'(x_0), \quad m_n = f'(x_n)$$
2. **Условия свободного провисания (естественный сплайн):** $S''(x_0) = 0$, $S''(x_n) = 0$. Дают уравнения:
   $$2m_0 + m_1 = 3\frac{y_1 - y_0}{h_0}, \quad m_{n-1} + 2m_n = 3\frac{y_n - y_{n-1}}{h_{n-1}}$$
3. **Условия «отсутствия узла»:** При отсутствии информации о поведении функции в краях:
   $$m_0 = m_1, \quad m_{n-1} = m_n \quad \Rightarrow \quad m_0 - m_1 = 0, \quad m_{n-1} - m_n = 0$$
4. **Периодические условия:** Если $y_0 = y_n$, то функция считается периодической. Граничные уравнения:
   $$m_0 = m_n, \quad \lambda_0 m_1 + \mu_0 m_{n-1} + 2m_0 = d_0$$

#### Матричная форма
Добавляя два граничных уравнения к системе (2), получаем линейную систему в матричном виде:
$$A \cdot \vec{m} = \vec{d}$$
где $A$ — матрица системы (обычно разреженная, трёхдиагональная), $\vec{m} = (m_0, m_1, \dots, m_n)^T$ — вектор неизвестных, $\vec{d}$ — вектор правых частей. Решив систему, находим наклоны $m_i$ и по формуле (1) строим сплайн $S(x)$.

---

### Квадратичные сплайны

**Квадратичные сплайны** состоят из квадратных трёхчленов ($m=2$). Построим сплайн, полиномы которого стыкуются **не в узлах интерполяции**.

Введём дополнительные точки соединения:
$$\tilde{x}_i = \frac{x_i + x_{i+1}}{2}, \quad i = 0, 1, \dots, n-1$$
«Кусочки» сплайна строятся на отрезках $[\tilde{x}_{i-1}, \tilde{x}_i]$. Крайние кусочки строятся на половинах крайних отрезков $[x_0, \tilde{x}_0]$ и $[\tilde{x}_{n-1}, x_n]$. Всего $n+1$ квадратный трёхчлен, каждый определяется 3 коэффициентами $\Rightarrow$ $3(n+1)$ неизвестных.

**Уравнения для нахождения коэффициентов:**
1. Условия интерполяции ($n+1$ уравнений): $S_i(x_i) = y_i$
2. Непрерывность сплайна ($n$ уравнений): $S_{i-1}(\tilde{x}_i) = S_i(\tilde{x}_i)$
3. Непрерывность первой производной ($n$ уравнений, дефект $k=1$): $S'_{i-1}(\tilde{x}_i) = S'_i(\tilde{x}_i)$
4. Два граничных условия (например, на производную): $S'_0(x_0) = f'(x_0)$, $S'_n(x_n) = f'(x_n)$

Итого $3n+3$ уравнений. Решая систему, находим коэффициенты квадратных трёхчленов для каждого отрезка.

## Примеры решения заданий

### Задание 1
Задана функция $f(x) = x^3$. Построить интерполяционное приближение сплайном третьей степени на отрезке $[0, 2]$ по узлам $x_0 = 0$, $x_1 = 1$, $x_2 = 2$ с граничными условиями $S'(0) = f'(0)$, $S'(2) = f'(2)$.

**Решение.**
Значения функции: $y_0 = 0$, $y_1 = 1$, $y_2 = 8$.
Шаги: $h_0 = h_1 = 1$.
Граничные условия: $m_0 = f'(0) = 0$, $m_2 = f'(2) = 12$.
Для $m_1$ из уравнения (2):
$$\mu_1 m_0 + 2m_1 + \lambda_1 m_2 = d_1$$
При $h_0=h_1=1 \Rightarrow \mu_1 = \lambda_1 = 0.5$.
$$d_1 = 3\left(0.5 \cdot \frac{1-0}{1} + 0.5 \cdot \frac{8-1}{1}\right) = 3 \cdot 4 = 12$$
$$0.5 \cdot 0 + 2m_1 + 0.5 \cdot 12 = 12 \Rightarrow 2m_1 = 6 \Rightarrow m_1 = 3$$
Получили: $m_0 = 0$, $m_1 = 3$, $m_2 = 12$.

Полиномы по формуле Эрмита:
$$S_0(x) = 3x^2 - 2x^3, \quad x \in [0, 1]$$
$$S_1(x) = 1 + 3(x-1) + 3(x-1)^2 + 2(x-1)^3, \quad x \in [1, 2]$$

**Проверка:**
$S_0(0)=0, S_0(1)=1, S_1(1)=1, S_1(2)=8$ (интерполяция) $\checkmark$
$S'_0(1) = 3, S'_1(1) = 3$ (гладкость) $\checkmark$

**Погрешность в средних точках:**
$x=0.5: f(0.5)=0.125, S_0(0.5)=0.625, |f-S|=0.5$
$x=1.5: f(1.5)=3.375, S_1(1.5)=4.375, |f-S|=1.0$
Погрешность высока из-за большого шага интерполяции.

### Задание 2
Построить **естественный кубический сплайн** в условиях задания 1 ($S''(0)=0, S''(2)=0$).

**Решение.**
Дополнительные уравнения:
$$2m_0 + m_1 = 3\frac{y_1-y_0}{h_0} = 3, \quad m_1 + 2m_2 = 3\frac{y_2-y_1}{h_1} = 21$$

### Задание 3. Квадратичный сплайн
Построить квадратичный сплайн для $f(x)=x^3$ на $[0, 2]$ по узлам $x_0=0, x_1=1, x_2=2$ с точками соединения $\tilde{x}_0=0.25, \tilde{x}_1=1, \tilde{x}_2=1.75$. Дефект $k=1$, граничные условия $S'_0(0)=f'(0), S'_2(2)=f'(2)$.

**Решение.**
Строим три полинома $S_i(x) = a_i x^2 + b_i x + c_i$ на отрезках $[0, 0.25]$, $[0.25, 1.75]$, $[1.75, 2]$.
Система уравнений из условий интерполяции, непрерывности и гладкости в точках соединения, а также граничных условий:
$$\begin{cases}
c_0 = 0 \\
a_1 + b_1 + c_1 = 1 \\
4a_2 + 2b_2 + c_2 = 8 \\
S_0(0.25) = S_1(0.25), \quad S_1(1.75) = S_2(1.75) \\
S'_0(0.25) = S'_1(0.25), \quad S'_1(1.75) = S'_2(1.75) \\
b_0 = 0 \\
4a_2 + b_2 = 12
\end{cases}$$
Решение системы:
$$a_0=6, b_0=0, c_0=0$$
$$a_1=0, b_1=3, c_1=-2$$
$$a_2=6, b_2=-12, c_2=8$$

Итоговые полиномы:
$$S_0(x) = 6x^2, \quad x \in [0, 0.25]$$
$$S_1(x) = 3x - 2, \quad x \in [0.25, 1.75]$$
$$S_2(x) = 6x^2 - 12x + 8, \quad x \in [1.75, 2]$$
