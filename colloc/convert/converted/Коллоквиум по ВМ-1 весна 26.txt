Часть I. Элементарная теория погрешностей 
1. Источники и классификация погрешностей. Абсолютная и относительная 
погрешности. Значащие цифры в десятичной записи числа. Округление. Верные 
значащие цифры. Правила записи приближѐнных чисел (примеры: лекция 1-1, с. 5-9, 
практика 1, задачи 1-2); 
2. Погрешности арифметических операций (примеры: лекция 1-1, с. 11-12, 15-17, 
практика 1, задача 3); 
3. Погрешности функций. Линейная оценка дифференциальной погрешности (примеры: 
лекция 1-1, с. 20-22, 15-17, практика 1, задачи 4-5). 
Часть II. Вычислительные задачи и методы 
1. Особенности современных вычислительных задач. Этапы решения вычислительной 
задачи. Вычислительные задачи, их корректность и обусловленность. Классификация 
вычислительных методов. 
Часть III. Аналитическое приближение табличных функций  
1. Задача приближенного вычисления функции. Интерполяция. Задача полиномиальной 
интерполяции. Теорема о единственности решения. Погрешность полиномиальной 
интерполяции (примеры: лекция 2-1, с. 5-6, практика 2, задачи 1-2); 
2. Интерполяционный многочлен Лагранжа. Схема Эйткена (примеры: лекция 2-1, с. 8-
10, практика 2, задача 3); 
3. Разделенные разности и их свойства. Интерполяционные многочлены Ньютона с 
разделенными разностями (примеры: лекция 2-2, с. 8-10, практика 2, задача 6); 
4. Конечные разности и их свойства. Интерполяционные многочлены Ньютона с 
конечными разностями (примеры: практика 2, задача 8); 
5. Интерполяционные многочлены Гаусса, Стирлинга и Бесселя (примеры: практика 2, 
построить многочлены Гаусса для таблицы из задачи 8, построить многочлены 
Стирлинга и Бесселя для таблицы из задачи 8); 
6. Задача аппроксимации табличной функции. Аппроксимация в классе обобщѐнных 
многочленов методом наименьших квадратов. Полиномиальная аппроксимация 
(примеры: практика 3, задачи 1-2); 
7. Задача аппроксимации табличной функции. Неполиномиальная аппроксимация 
(примеры: практика 3, задача 4(2)); 
8. Многочлены Чебышева, их свойства (примеры: практика 4, задача 1; построить 
многочлен Чебышева заданной степени 3-мя способами); 
9. Задача минимизация оценки остаточного члена интерполяции, теоремы Фабера и 
Марцинкевича. Решение с помощью многочленов Чебышева (примеры: практика 4, 
задачи 3-5, лекция 4-2, с. 4);
